# 1688 批量修改类目与商品信息

这是一个 Tampermonkey 用户脚本，用于批量处理 1688 商品的类目、标题、属性、SKU、发货分档和件重尺。

> 当前版本：`v0.7.1`

v0.7.1 修复供货方式中“定制”和说明文字放在同一 span 时定位失败的问题；点击唯一复选框并重新读取原生选中状态，避免误读“现货”的选中样式或重复点击取消选择。

当前规则：

- 进入“修改详情 → 修改类目”。
- 搜索并选择面板指定的末级类目。
- 支持新版 `offer-new.1688.com/select.htm` 类目选择页，并精确识别“类目搜索，可输入关键词搜索类目”输入框。
- 类目路径不符合面板中的预期路径时停止，防止选错。
- 产品属性中的空白必填项填写 `/`；默认不覆盖原有内容。
- “特殊用途化妆品”选择“否”。
- 支持普通现货模式，发货时间选择“48小时发货”。
- 支持勾选“定制”，并自动新增发货分档：1～2 个 48 小时，3 个以上 72 小时。
- 支持修改“颜色分类”和“计量单位”（默认为 `个`）。
- 长、宽、高和重量由开始前的悬浮面板填写。
- 支持文字替换或调用 SenseNova 兼容接口的 AI 标题改写。
- 支持“仅替换标题”模式，不改动类目和其他商品信息。
- 测试模式在提交前暂停；批量是否自动提交取决于“批量自动发布”开关（新安装默认开启）。

## 从详情图批量补主图

1. 更新油猴脚本并刷新1688页面，在面板顶部勾选“仅补主图，其他不更改”。
2. 设置主图目标数量，默认为4张。已有足够图片的商品跳过。
3. 先打开一件商品，点击“测试当前商品”。测试会补图并停在提交前，检查新增图片内容后再保存。
4. 在商品列表选择目标商品并“读取本页选中”，或者粘贴修改详情链接，点击“开始 / 重新开始批量”。仅补图不要求填写重量、类目或AI密钥。

脚本读取当前商品同源详情编辑器/iframe或源码文本中的阿里图片地址，筛选短边至少800px、宽高比0.8～1.25、5MB以内的JPEG/PNG/WebP。通过图片URL和缩小后的画面特征去重，按详情顺序补缺少的数量。尺寸筛选不能判断图片上的文字和卖点是否适合主图，请在首件测试时核对。长详情图不会自动裁切。

上传通过主图区实际的文件上传控件进行；新增图片数量、原图顺序、图片画面都需通过校验。保存成功后会重新打开同一商品确认主图列表，再继续下一件。原主图、首图顺序、白底图和详情保持原样。

“完整流程中补主图”可把补图接在原来的字段填写之后；“仅替换标题”模式始终跳过补图。若油猴请求图片域名权限，需要允许 `alicdn.com` / `1688.com`，脚本不发送AI密钥获取图片。

找不到独立主图区、合适候选不足、跨域详情编辑器不可读、图片弹窗没有唯一上传控件、上传或保存校验失败时会暂停。上传结果不明不会自动重传；人工核对页面后可点击“确认当前主图并解除补图暂停”，再测试继续。

本版本通过模拟DOM和批次状态测试；当前1688实际上传弹窗尚未完成实机验证。若日志提示不支持，请保留页面/弹窗供定位，不要直接标记成功跳过。

## 安装

1. Chrome 安装 Tampermonkey。
2. 在 Tampermonkey 中新建脚本。
3. 删除模板内容，粘贴 `1688-batch-category-editor.user.js` 全部内容并保存。
4. 刷新1688商品管理页面，右上角应出现“1688 批量类目修改”面板。

## 首次使用（必须先用一个商品测试）

1. 打开一个商品的修改页面。
2. 面板填写目标类目、完整类目路径、长宽高和重量。如需定制，再填写颜色分类目标值并勾选“定制”。
3. 暂时不勾选“批量自动发布”。
4. 点击“测试当前商品”。脚本必须依次执行：修改类目 → 确认重选提示 → 选择目标类目 → 继续完善 → 填写属性、SKU 和发货服务。
5. 核对所有内容。确认页面字段都能正确识别后，才批量运行。

当页面出现“重选类目可能导致部分信息丢失”提示时，脚本会保留页面默认的“暂存草稿后继续”选中状态并点击确认。进入类目页后，只有“已选类目”与预期完整路径一致时，才继续到完善页。

## 批量队列

在商品管理列表勾选商品后，点击“读取本页选中”。如果1688页面的“修改详情”不是实际链接，脚本无法自动提取，可将每个商品的修改详情网址逐行粘贴到面板。

点击“开始/继续批量”后，脚本跨页面保存队列。关闭“批量自动发布”时，每件商品在提交前暂停：

- 检查正确：点击“提交当前商品并继续”。
- 已经人工提交成功：点击“标记成功并下一个”。
- 发现错误：点击“停止”。

点击“开始/继续批量”会把当前面板中的链接视为一个新批次，并从第1条开始。运行途中页面跳转后，脚本会从保存的进度自动继续。

## 限制

已确认该账号的商品列表位于工作台 iframe，每个商品行都提供带 `offerId` 的真实“修改详情”链接；链接会跳转到新版 `offer-new.1688.com` 编辑器。新版编辑器体积较大，类目弹窗、下拉框和最终提交按钮仍需用一个商品做首测校准。脚本不会绕过验证码、登录验证或平台审核。

AI 密钥只保存在 Tampermonkey 本地存储中，不写入脚本源码。

## 开发校验

`pnpm install --ignore-scripts` 后执行 `pnpm test`。测试使用模拟的主图、白底图和详情编辑器，覆盖计数、去重、模式隔离、未确认上传暂停及保存回读，不会访问或发布真实商品。
